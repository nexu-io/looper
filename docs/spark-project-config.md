# OpenMotion configuration on Spark

[The validation workflow](../.github/workflows/spark-project-config.yml) tests the project configuration with fixtures and builds the candidate tool at the same commit. It uses a GitHub-hosted runner without deployment credentials.

The [project entry](../tools/spark-project-config/openmotion.toml) binds OpenMotion to `nexu-io/html-anything` and its `feature/motion` base. The pilot keeps discovery and auto-merge disabled for this project. Its Reviewer uses the built-in method and requires `maintainability-review`. Complete the [isolated effectiveness evaluation](../skills/maintainability-review/README.md#verification-versus-effectiveness) before starting live reviews.

The candidate tool takes `-config` (existing Looper TOML), `-repo-path` (the OpenMotion checkout root with `origin/feature/motion` fetched), and `-output` (a new TOML file). It keeps the existing configuration and validates the combined file with Looper's loader. The candidate contains the existing configuration, so keep it on the authorized execution host and out of CI logs and artifacts. Activation requires a separate protected deployment job. Applying the project entry as a complete daemon configuration would omit existing projects from the [startup import](adr/0012-sqlite-project-authority.md).

For activation, use a protected GitHub environment restricted to the reviewed `main` branch and an authorized execution route to Spark. Keep write credentials in CI and do not give public PR workflows access to Spark. The deployment job must serialize changes to this daemon, verify that the tested revision still matches remote `main` immediately before applying, and record the source SHA and run ID. Before replacing the live file, check for project catalog conflicts and validate the candidate with the daemon's effective startup configuration. Coordinate the required restart with the daemon owner. Verify the OpenMotion entry, the installed Skill, and the rest of the catalog after restart. Recovery uses the same protected workflow.
