## loopernet 的依赖边界

loopernet 是已有的设备身份、认证及在线连接基础设施。当前 Plane 派发链路依赖它，collab 进程内启动轻量客户端，复用设备凭证和心跳；本次测试另外启动了本地 loopernet 服务。

任务内容与状态通过 Plane 的签名 inbox／claim／transition API 交换；loopernet 不负责 Agent 的需求理解、代码执行、飞书对话或 PR 跟进。未绑定网络时，客户端 Start 可以不连接而返回，纯本地 `collab run` 不要求先绑定设备。`collab` 独立是指无需 Friday、完整 daemon 和固定 Planner 流程，不表示 Plane 派发没有外部服务依赖。
